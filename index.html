03 / 技术方向

两条腿走路：自研 + 集成

自研核心建立壁垒，成熟系统集成快速变现。两条路径并行，互为支撑。

03A / 护城河

自研核心技术

掌握视觉算法、智能体框架、数据标注平台的自主知识产权，形成不可替代的技术壁垒。

工业视觉检测

基于 YOLO / SAM 等模型，针对石化、农业、建材等场景微调训练，形成自有知识产权的模型库。

→ 石化管道巡检 · 农产品分拣 · 建材缺陷检测

智能体（Agent）开发框架

轻量级 LLM Agent 编排框架，用于快速构建企业级智能客服、知识库问答、自动报告生成。

→ 智能办公 · 业务流程自动化 · 企业知识库

数据标注与管理平台

基于 yolo-label-vs 项目持续迭代，沉淀为内部提效工具 + 对外服务 SaaS。

→ 降低研发成本 · 可独立对外提供服务
03B / 变现器

供应商集成能力

对于成熟的 CRM / MES / ERP / 云系统，坚决不重复造轮子，通过合作集成方式快速交付。

CRM / OA / ERP

与用友、金蝶或本地系统集成商合作，负责需求对接与 AI 模块嵌入。

→ 快速响应基础数字化需求 · 稳定现金流

MES / WMS

→ 制造业客户 · AI 应用数据入口

云基础设施

与主流云厂商合作，按需付费，降低基础设施成本，保障数据安全。

→ 弹性伸缩 · 数据合规
